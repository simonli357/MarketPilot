# Decisions

Create a decision record only for a durable, material choice whose rationale future work must retain. Examples include a public contract, persistence model, security boundary, platform strategy, or dependency with meaningful lock-in.

Do not create a record for routine implementation choices, temporary exploration, task status, or a decision already owned clearly by a block.

Copy `DEC-template.md` to `DEC-<number>-<slug>.md`. Accepted records are immutable except for links and status; supersede them with a new record instead of rewriting history.

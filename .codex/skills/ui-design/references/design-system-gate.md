# Design System Gate

An option is incomplete until all applicable rows have exact values and usage rules.

| Area | Required detail |
| --- | --- |
| Color | Semantic token names, exact values, contrast and state usage |
| Typography | Families, sizes, weights, line heights, usage, fallbacks |
| Spacing and shape | Scale, density, radius, borders, elevation, stable dimensions |
| Layout | Grids, regions, min/max constraints, breakpoints, overflow behavior |
| Components | Anatomy, variants, default/hover/focus/active/disabled/loading/error states |
| Product states | Empty, loading, ready, stale, degraded, offline, denied, destructive states |
| Responsive | Exact reference viewports and layout changes |
| Motion | Purpose, duration, easing, reduced-motion behavior |
| Assets | Runtime path, format, dimensions, source, usage, fallback policy |
| Accessibility | Semantics, labels, keyboard, focus, contrast, touch targets |
| Fidelity | What must match, what may adapt, comparison method, approval owner |

Generated OCR text and physically impossible details may be corrected during translation, but the approved coded reference and decision must make every correction explicit.
